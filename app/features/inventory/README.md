# Módulo Inventario

Las nuevas pantallas, componentes y reglas de inventario se organizan aquí.

- `components/`: componentes reutilizables de la interfaz.
- `services/`: casos de uso y acceso a datos.
- `types.ts`: contratos del módulo cuando se extraigan de la interfaz actual.

La interfaz existente continúa en `app/inventory-app.tsx` hasta que cada sección se extraiga y se pruebe de forma incremental.

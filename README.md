# Juanitos · Inventario y compras

Prototipo funcional para probar un flujo simple de inventario y Solicitud de compra en un restaurante.

## Alcance

La aplicación separa los productos de Cocina y Barra, permite registrar ingresos de mercadería y conteos físicos, conserva un historial básico y muestra al dueño los faltantes junto con el informe de stock actual.

El stock se actualiza únicamente mediante ingresos o conteos. El prototipo no incluye ventas, caja, precios, producción, stock mínimo ni descuentos automáticos por consumo.

## Uso local

```bash
npm install
npm run dev
```

La base de datos local se crea y carga automáticamente con los productos de ejemplo al abrir la aplicación por primera vez.
